# Imagens da aplicação

## Dispositivo usado

- **Hardware:** Samsung A52s
- **Android:** 14

## Compilação

- **OS de desenvolvimento:**
  - Windows 11 25H2 x64
  - Tsurugi Linux 26.03 x64
- **Flutter:** 3.47.3 e 3.47.4
- **Dart:** 3.13.3
- **Java:** OpenJDK 25 LTS

## Imagens

- Versão release alpha 3 — 14/09/2026, revisão E — 15/09/2026
