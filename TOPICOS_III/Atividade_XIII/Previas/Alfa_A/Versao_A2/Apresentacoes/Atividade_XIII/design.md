## Design Concept
本資料は、ペットケア事業（PetCuida）の成長戦略および事業性評価を目的としたビジネスプレゼンテーションである。デザインの基盤として、Monocleの知的で整然としたエディトリアルレイアウトと、無印良品の温かみのあるミニマリズムを借用する。ペット関連スタートアップにありがちな「ネオンオレンジと肉球マーク」という陳腐な表現を完全に排除し、信頼とケアを体現するパレットを構築する。全体的な温度感は「温かみのある紙（Papery）」。ベースにはオートミールのようなオフホワイトを敷き、メインカラーには親しみやすさと地に足のついたビジネスを象徴するテラコッタ（赤茶色）を採用。テキストには深いチャコールグレーを用い、事業計画としての説得力を持たせる。タイポグラフィは、見出しに誠実な明朝体、本文に可読性の高いゴシック体を組み合わせ、信頼感とモダニティを両立させる。

## Visual Language
*   **Imagery:** 背景を白抜きにしたペット単体の写真ではなく、飼い主とペットが自然環境で過ごすライフスタイル写真（彩度をやや落とし、温かみを持たせたもの）をヒーローイメージやサポート画像として使用する。
*   **Containers:** 余白を優先しつつ、複雑なデータや財務情報には角丸（4px）の白背景カード（ドロップシャドウなし、薄いボーダーのみ）を使用し、情報を整理する。
*   **Icons:** ソリッドタイプを採用。装飾目的ではなく、指標やリスク項目をナビゲートするマーカーとしてのみミニマルに使用する。
*   **Dataviz:** 表は横罫線のみ（ヘッダー下はテラコッタ色、他はグレー）とする。チャートはテラコッタを主軸に、比較対象としてセージグリーン（#7A8B76）を使用する。
*   **Motif:** 画面上部（上端から40pxの位置）を横断する、太さ2pxのテラコッタ色の水平ライン。全ページに配置し、視覚的な一貫性を担保する。

## Layout Directives
*   **Global:** マージンは上下左右60px。モチーフ（2pxライン）を上部に固定。スライド番号は右下、出典元は左下に配置。テキストは左揃えを原則とする。
*   **Cover:** テラコッタ色の背景に白文字。画面下半分を占める高品質なライフスタイル写真を配置し、温かみとスケール感を演出する。
*   **Table of Contents:** 2カラム構成。左側に大見出しと短いリード文、右側に各セクションのタイトルとページ番号をリスト化。
*   **Section Dividers:** オートミール背景。中央に大きくセクション番号とタイトルを明朝体で配置し、下部にテラコッタの短いアクセントラインを引く。
*   **Closing:** カバーデザインを踏襲。写真のトーンを合わせつつ、右側に連絡先や次のステップへのアクションコールを配置。
*   **Slide Map:**

## Design Tokens
| token | hex | usage |
| :--- | :--- | :--- |
| primary | `#C05640` | 見出しのアクセント、モチーフライン、主要な強調箇所 |
| bg-page | `#F7F5F0` | スライドの基本背景色（オートミール） |
| bg-card | `#FFFFFF` | データやテキストブロックの背景（カード用） |
| text-main | `#2D2A26` | 本文、主要な見出し（チャコール） |
| text-muted | `#6B665E` | キャプション、補足テキスト、メタデータ |
| border-divider | `#E2DCD0` | カードの枠線、表の区切り線 |
| chart-1 | `#C05640` | グラフのメインデータ系列 |
| chart-2 | `#7A8B76` | グラフのサブデータ系列（セージグリーン） |

| role | family | size (px) | applies_to |
| :--- | :--- | :--- | :--- |
| display | Noto Serif JP | 48 | カバータイトル、セクション区切り |

## Guardrails
*   **Forbidden:** 肉球、骨、犬小屋などのクリシェなベクターイラストの使用を禁ずる。
*   **Forbidden:** 視覚的なノイズとなるドロップシャドウやグラデーションの使用を禁ずる。
*   **Forbidden:** 純白（#FFFFFF）をページ全体の背景として使用しない（カード背景のみ可）。
*   **Forbidden:** 信号機カラー（赤・黄・緑）を状態表示にそのまま使用しない。パレット内の色調に合わせるか、濃淡で表現すること。
*   **Size floors:** 本文は18px以上、キャプション・チャートラベルは12px以上を厳守すること。
